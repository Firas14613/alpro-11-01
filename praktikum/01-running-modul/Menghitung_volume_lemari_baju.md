penggaris, pensil, kertas

2. Menggunakan Pensil untuk memcatat panjang di atas Kertas
3. Menggunakan penggaris untuk mengukur lebar
4. Menggunakan Pensil untuk memcatat lebar di atas Kertas
5. Menggunakan penggaris untuk mengukur tinggi
6. Menggunakan Pensil untuk memcatat tinggi di atas Kertas
7. Menghitung Panjang x Lebar x Tinggi
8. Catat hasil akhirnya di atas kertas
